# Server (`server/`)

Node 22, plain ES modules, one runtime dependency (`@anthropic-ai/sdk`). Serves `web/` statically and the `/api/*` routes from ARCHITECTURE.md §3, §8 (sketch) and §9 (story actions). Runs fully offline in **mock mode**.

```
export PATH=~/.nvm/versions/node/v22.22.3/bin:$PATH
npm install          # once
npm start            # http://localhost:8870   (PORT=... to change)
npm test             # node --test tests/server/**  (80 tests, all mock, no key needed)
npm run live-smoke   # hits every endpoint with the live models; skips cleanly without a key
node tests/server/render-stock.mjs [key ...] [--view=bird|eye]   # renders every mock stock asset through the real gallery + paint engine -> shots/server/
```

## Endpoints
All JSON in / JSON out, body limit 1 MB. A JSON body that is not an object is treated as `{}`. CORS: only `localhost` / `127.0.0.1` / `[::1]` origins get the header. Every response carries `meta: { mind: 'live'|'mock'|'cache', ms, model?, speed?, usage?, liveError? }`.

- `GET /api/health` → `{ ok, mock, mockReason, models:{logic, visual, sketch, command}, stt, catalogue, letters, assets, buildApi, sketch:true, scenes, fastMode, stock:[keys], letterPurposes, timeouts, talk, conflicts, minds }`. `minds` (§18): `{ status:'live'|'mock'|'off', models:{persona, director}, directorEveryMs, calls:{cast, think, converse, converseTurns, reflect, direct, talk, mock, budget, failed}, usage:{model:{input, output, cacheRead, cacheWrite, calls, usd}}, usd:{ total, perHour (a 10-min window), window, uptimeMin, rates }, budget:{ maxPerMin, usedLastMin, rejected }, cache:{ sharedPrefixTokensEst, minimumToCache: 4096 }, timeouts, actions }`.
- `POST /api/command` `{ transcript, scene:'earth'|'moon', pointer:{x,z}|null, mark?, selected?, snapshot }` → `{ actions:[Action], say?:{from, text}, scene, mark?, meta }`. ART_DIRECTION §15 adds **`found_institution { kind, members?, leader?, name?, request? }`** and **`resolve_conflict { conflictId?, how }`** (see **Conflicts and institutions** below). `mark` is the cursor mark (§10, see **Marks** below). Logic model, effort **low**, structured output, target < 4 s (timeout 25 s). Actions are normalised to §4 + §9: unknown ids are dropped, `kind` is always present (`null` for new things, with `request` + `name`), `near` refs are resolved to building ids, `count` only when > 1, `moon` only when `scene === 'moon'`, `go_moon` only on earth, one `go_moon` / `show` / `visit_neighbour` per utterance. `scene` may also ride on `snapshot.scene`.
- `POST /api/society` `{ snapshot, recent, wants?:['report'] }` → `{ letters:[LetterDraft], events, meta }`. Logic model, effort **medium**. Max 3 letters.
- `POST /api/letter` `{ purpose, agent?, context?, snapshot }` → `{ subject, body, options:[{label, says}], from:{kind,id,name}, kind, purpose, meta }`. Logic model, effort **low**. Purposes: `refusal | skill_answer | report | reply` (folk), **`conflict`** (the minister, `agent`, brings `context.conflict { id, kind, summary, parties, severity, place }` with advice in their traits' voice and executable quick replies; `context.institutions` lists the kinds already founded; an empty `agent` makes it the Ministry's) and the story set `election` (one letter signed by all three nations; options include "let's go to the moon" and "build a rocket"), `envoy` (`context.neighbour` id or object, `context.kind` greeting|trade|envy|alliance|complaint|news, `give`/`get`), `gift_thanks` (`context.gift`), `shadeling_contact | shadeling_seed | shadeling_golden | shadeling_farewell` (the moon's lantern creatures: short luminous lines, from `{kind:'neighbour', id:'shadelings', name:'the shadelings'}`). When no neighbour is given, "them" is the nation that wrote the most recent letter in the snapshot (`letters` / `recent` / `unread`), else the friendliest. Every option's `says` is executable by the parser on its scene (a test checks this).
- `POST /api/sketch` `{ request, snapshot }` → `{ name, category, footprint:{w,d}, height, parts:[{shape, x,y,z, w,h,d, r, rot, color}], meta }` (ARCHITECTURE §8), ≤ 16 parts, `rot` is a turn about the vertical axis, colours are hexes from the Red arch grammar (`SKETCH_PALETTE`; off-palette hexes become limestone). Live: the `sketch` model (default = logic) at effort low, 12 s one shot (no SDK retry: a late sketch is useless, the mock massing is drawn instead). Mock: `mockSketch` per keyword family (lighthouse / rocket / duck / dragon / statue / boat / tree / tower / generic), scaled by size words (giant 1.8×, small 0.7×), also carrying `family` and `scale`.
- `POST /api/codegen` `{ request, kindHint?, snapshot }` → **SSE** `text/event-stream`: `status {stage:'drafting'|'writing'|'checking'|'repairing', note}` …, then `done {asset, meta:{mind, speed?, category, stock?}}` or `error {message, code}`. Visual model, effort **high**, streamed; **fast mode first** (`speed:'fast'` + beta `fast-mode-2026-02-01`), standard on 429 / 400 / any error of the fast attempt (the same attempt is retried, with a `drafting` note "the fast lane is closed"). Whole-request budget 270 s (`AGORA_CODEGEN_BUDGET_MS`), then the mock stock plan. Cached assets answer at once (`meta.mind:'cache'`), matched on the request noun ("another rocket" hits, "a giant rocket" does not). `asset = { id:'gen-<slug>-<hash>', name, aliases, meta:{footprint, cost, workers, skill, buildSeconds, perDay, housing, desc, category}, code, generated:true, request, speed?, savedAt }`. The system prompt embeds `web/js/buildings/BUILD_API.md`, read from disk at request time.
- **`POST /api/talk`** (ART_DIRECTION §11) `{ agentId, agent:{ name, species, trade, traits, mood, moodWord, skills, known, job, status, homeless, isMinister, fleet, memory }, text, history:[{you, me}], snapshot }` (= the sim's `game.talkContext(id, text)`) → `{ agentId, reply, mood, action, intent?, meta }`. `reply` is **simple and short**: 1–2 plain sentences, ≤ 170 chars (`trimReply`; a two-word question such as "A well?" rides with the sentence after it), warm, in character. `mood` −5..5. `action` is `null` or `{ type:'build', request, text }` (the folk offered to build something: feed `game.talk(id, text, result)` and the sim places it near them with them on the crew), `{ type:'rest' }`, `{ type:'assign', text:<building> }`, `{ type:'ask_crowd', text:<question> }`, `{ type:'call_meeting' }`. Live: the command model at effort **low**, structured output (`TALK_SCHEMA`: **0 union-typed parameters**), one shot (no SDK retry), 15 s, prompt `server/prompts/talk.md`; the user block carries the agent, the text, the last 6 exchanges and a trimmed snapshot (name, stage, day, res, hungry, minister, buildings, agents with their `work`, neighbours). Mock: `server/mock/talk.js` → the sim's own `mockTalk` (`web/js/sim/talk.js`), templated by intent (greeting, how are you, who are you, what do you do, skills, what do you want, the town, the minister, the neighbours, food, home, fleet, thanks, rest, build → action, bye, yes / no), trait-coloured and deterministic; `intent` is echoed in mock answers. Health reports `talk: true`.
- **`POST /api/minds/cast | think | converse | reflect | direct`** (ART_DIRECTION §18, `docs/minds.md`). Bodies are what the sim builds (`game.castRequest()`, `game.thinkRequest(id)`, `game.converseRequest(cid)`, `game.reflectRequest(id)`, `game.directRequest(reason)`); answers go to `game.castPersonas` / `applyIntent` / `applyConversation` / `reflect` / `applyDirection`. `cast` → `{ personas:[{ id, backstory, voice, quirks, values, fear, goal, opinions:{id: line}, secret }], tensions, meta }` (Fable, effort medium, 90 s; a short answer is topped up from the mock). `think` → `{ intent:{ type, target, text, place }, say (≤ 12 words), memory_note, mood_delta, meta }` (Haiku 4.5, plain: no betas / fallbacks / effort / thinking, the persona prefix cached in two system blocks, 400 tokens, **4.5 s one shot**). `converse` → `{ lines:[{ speaker, text ≤ 14 words }], outcome:{ affinity, noteA, noteB, spawns:'none'|'letter'|'conflict', subject }, meta }` (`turns` 2–4 alternating Haiku calls, each with that speaker's persona prefix and the transcript so far, 4 s each). `reflect` → `{ reflection, meta }` (Haiku, 7 s). `direct` → `{ arc_note, events:[{ kind:'conflict'|'visitor'|'weather'|'festival'|'opportunity', agentIds, neighbourId, topic, text, severity }], nudges:[{ agentId, goal }], minister_briefing:{ subject, body }, meta }` (Fable, effort medium, 60 s). Persona calls are capped at `AGORA_MINDS_MAX_PER_MIN` a minute: over it the mock answers with `meta.budget:true`. `AGORA_MINDS=off` → 503 `{ code:'off' }`. Mock: the sim's own minds (`web/js/sim/minds.js`), deterministic.
- **`POST /api/talk` with a persona**: after the cast the sim's `talkContext` carries `persona` and `mind { memory, reflections, goal, relationships }`; the route then answers on the persona model with the persona prefix (same reply shape, `meta.model` = Haiku); without a persona it is unchanged. The mock reply takes the persona's voice.
- `GET /api/assets` → **array** of cached assets (with code), for `game.catalog.add` + `library.register` on boot. `GET /api/assets/<id>.js` → one cached asset's raw code (`text/javascript`), so `web/gallery.html?code=/api/assets/<id>.js&only=gen-<id>` shows a live-generated asset (`node tests/server/render-stock.mjs --assets` renders them all).
- `GET /api/stock` → the mock library `[{key, name, aliases, category, generic}]`; `GET /api/stock/<key>.js[?request=…]` → raw `build(api)` code (`text/javascript`), which is what `web/gallery.html?code=/api/stock/duck.js&only=gen-duck` loads.

### Conflicts and institutions (ART_DIRECTION §15)
Two new action types, **no new union-typed parameters** (the flat action object gained the plain strings `conflictId` and `how`; `COMMAND_SCHEMA` still counts 3):
- `found_institution` — `kind` is what the sovereign called it (free text: "police patrol", "night watch", "court", "school", "builders' guild", "festival committee", "a council", "a choir"), `count` → `members` (0 = the kind's default), `agentId` → `leader` (checked against the snapshot), `request` → a place to raise for it ("a watchtower"), `name` → a title when given. Normalised to `{ type, kind, members?, leader?, name?, request? }`; the sim's `institutionKind` maps the words to patrol | watch | court | school | guild | festival | generic.
- `resolve_conflict` — `conflictId` from `snapshot.conflicts` (an unknown id is dropped, not the action: the sim takes the newest open one), `how` = talk | punish | compensate | ignore or the sovereign's own words (kept, ≤ 120 chars; the sim's `normaliseHow` maps them).
- The snapshot the server reads gained `conflicts[{ id, kind, parties, severity, status, summary }]`, `institutions[{ id, kind, name, members, leader, badge }]` and `agents[].role`; the command, society, letter and talk prompts describe them (command rule 12; society: a party may write their side, never invent or resolve one; letter: the `conflict` purpose; talk: `agent.role` / `agent.conflict`).
- **Mock parser** (`server/mock/intent.js`): institutions from "start / set up / make / open / form / found / organise / we need / guard … a police patrol (team) / night watch / court / school / builders' guild / festival committee / council / militia / choir…" and bare noun phrases ("a police patrol team of 3 led by Olla" → members 3, leader), "guards with a watchtower" → `request: 'a watchtower'`; "build a watchtower" stays a `build`. Conflict answers: "talk to them / have a word / hear them out / calm them down" → talk, "punish the thief / punish them both / lock him up / fine them" → punish, "compensate them / give them bread / make it up to them" → compensate, "ignore the quarrel / the theft" → ignore on that one; the words aim at a conflict by kind (thief → theft) or by a party's name ("talk to Momo"); a bare "ignore it" answers the latest letter `no` (the conflict letter's no = ignore). "Talk to Olla" with Olla in no dispute is left alone (not a settlement). The clause splitter also splits on "and start / set up / talk / punish / compensate / ignore…" so "punish the thief and start a police patrol" is two actions. `say`: "A police patrol is founded; the Ministry picks the hands." / "It will be punished, and seen to be." …
- **Mock letters** (`server/mock/letters.js`): purpose `conflict` → the minister's letter with trait-coloured advice and the per-kind quick replies (every `says` is executable; a test checks it), from the minister or the Ministry. `LETTER_KINDS` gained `conflict`.
- Health reports `conflicts: true`. Tests: `tests/server/institutions.test.mjs` (schema, parser phrasings, the normaliser, the letter purpose, and a round trip: the sim writes the letter, the server parses its quick replies, the sim applies them).

### Marks (ARCHITECTURE §10, ART_DIRECTION §5)
`mark` on `/api/command` is what the sovereign drew: the marks module's `summarize()` (`{ kind:'point'|'area'|'line', centroid:{x,z}, bbox, areaM2 | length, nearest }`) or its `current()` (`{kind:'point', x, z}` / `{kind:'area', poly, …}` / `{kind:'line', pts, …}`), with an optional `id`. `normaliseMark` (schemas.js) accepts both, rounds to 0.1 m, keeps `poly` / `pts` / `id` when present, and reads a bbox as `{x0,z0,x1,z1}`, `{x,z,w,d}` or `{min,max}`; an area / line with no extent is a point; junk is `null`.
- **The model** sees `summariseMark(mark)` in the user block (no polygon, no id) and the prompt's rule 0: with a mark, "here / there / this / this area / along this", or a bare thing with no place, is `at.mode:'mark'`; area words with an area mark pick the area kind (`field, forest, orchard, vineyard, plaza, garden`, plus `farm`), line words with a line mark the line kind (`road, wall, fence, river`, plus `bridge`); a single thing named for an area sits at its centroid.
- **The normaliser** (`normaliseAction`, opts `{ mark, pointer }`): while a mark exists, `pointer` **and** `mark` answers both become `{ mode:'mark', x, z, mark }` with x/z = the centroid and `mark` = the full normalised mark (polygon / stroke / id included, so `game.apply` can fill it with no extra lookup); `mark` with no mark present degrades to `pointer` (or `auto` without a pointer). `center`, `near`, `water`, `auto` are never touched by a mark ("a forest in the middle" with an outline on the paper still goes to the middle). `AT_MODES` now lists `mark` and `water` (the sim's floating mode; `at.water:'lake'|'sea'`).
- **The mock parser** follows the same rules (`MARK_RE`, `MARK_IS_RE`: "this is a field", "make this a market district", "this area should be a forest", "let this be a garden", "a road along here", "burası tarla olsun"), and the Ministry's `say` names the mark ("A field, filling the outline you drew." / "A house, exactly on your mark." / "A road, along the line you drew." / "A house, at the heart of the outline you drew.").
- **The catalogue** gained `shape` (`point | area | line`) and `category` in the prompt JSON, and the kinds `field, forest, orchard, vineyard, plaza` (area), `wall, fence, river` (line); `road` is a line, `garden` an area. `field(s)/crops/meadow` no longer alias `farm`, nor `forest/woods/orchard` `grove` (farm and grove stay point prefabs). Turkish: tarla, orman, bağ, meydan, duvar, çit, nehir/dere/kanal.
- The response echoes `mark` (the summary) so the client can check what the server acted on.

Snapshot fields the server reads (all optional, both the §3 contract names and the sim's own `game.snapshot()` names): `day, stage, resources|res, buildings[{id,kind,name,status,housing?}], agents[{id,name,species,trade,status,traits,skills,mood,role?}], letters|unread|recent[{id,subject,from(name or {kind,id,name}),options?,resolved?}]` (**pass unresolved letters with ids** so "yes/no" can answer them), `neighbours[{id,name,leaderName,leaderSpecies,temperament,attitude}], minister, unlocked, scene, name, conflicts[{id,kind,parties,status,summary}], institutions[{id,kind,name,members}]`.

## Timeouts: server vs client (`web/js/net/api.js` TIMEOUTS)
The client must sit **above** the server's live timeout so a slow mind falls back to the mock answer instead of the client erroring first:

| route | server live timeout | client today | verdict |
|---|---|---|---|
| command | 25 s | 32 s | ok |
| letter | 30 s | 38 s | ok |
| society | 60 s | 70 s | ok |
| sketch | 12 s, no retry | 32 s | ok (16 s would do; the client already races it against codegen) |
| talk | 15 s, no retry (persona talk 12 s) | 22 s | ok |
| minds/think | 4.5 s one shot | the loop's 5 s (`MIND.timeoutMs`); the net call ≥ 5.5 s | the rules answer for that folk on a miss |
| minds/converse | 2–4 × 4 s | the loop's 12 s; net ≥ 18 s | the mock lines on a miss |
| minds/reflect | 7 s | the loop's 8 s; net ≥ 9 s | |
| minds/cast | 90 s | the loop's 60 s; net ≥ 95 s | the mock cast on a miss (the loop fills in at 60 s) |
| minds/direct | 60 s | the loop's 90 s; net ≥ 65 s | the mock direction on a miss |
| codegen | 110 s fast / 170 s standard per attempt, **270 s whole request**, then mock | 300 s total, 120 s idle | ok (the server pings every 10 s, so idle never trips) |

So: **no client change is required**. If the lead wants tighter UX: `sketch: 16000`, and `command` could drop to 30 s. Never below the server numbers.

## Mock vs live
**Mock** (default without a key): `intent.js` parses the demo script, every director beat and every chip (`tests/server/intent-phase3.test.mjs` reads `DEFAULT_BEATS`, `DEFAULT_CHIPS`, `MORE_CHIPS` from the real files):
- builds: catalogue aliases incl. plurals/Turkish, **kinds resolve from the NOUN only** (location tails stripped: "a bakery near the windmill"), bare noun phrases are builds ("a dragon statue in the square", "two boats by the dock"), a catalogue noun with an unusual modifier is a new thing ("a giant tree", "a clock tower", "a glass house" → `kind:null`), the head noun decides ("a teapot the size of a house" is a teapot), "in the lake / in the square" place things, and when the sovereign both points and names a place the pointer wins ("put a giant rubber duck there, in the lake").
- diplomacy: `send_gift` ("send them a basket of bread", "send bread to our neighbours", "a gift for Little Lantern", "komşulara ekmek gönder"; "them" = the nation most recently in a letter, else the friendliest; the gift text and a `give` bundle are inferred, Turkish items translated), `visit_neighbour` (a nation named: "show me Grey Harbour", "visit the Lantern", "fly to Sorrento"), `show globe` ("show me the neighbours / the world", "komşuları göster"), `show home` ("come back home", "take us back down"). A nation's envy letter that asks for a gift is answered (`reply_letter yes`) instead of doubled.
- letters: yes/no words incl. the sim's own option phrases ("accept the trade with X", "ally with X", "apologise to X" → yes; "decline", "ignore it", "dismiss it", "not yet" → no), aimed at the named nation's letter when there is one, else the latest; letters come from `letters` or the sim's `unread` / `recent`.
- the moon: `go_moon` on earth ("let's go to the moon", "to the moon", "launch", "aya gidelim", "visit the shadelings"); with `scene:'moon'` the six verbs `seed | golden_hour | daylight | greet | gift | go_home` ("offer them a seed", "wait for the evening", "bring back the day", "we come in peace", "give them a gift", "let's go home", plus Turkish: tohum ver, akşamı bekleyelim, gündüz, merhaba / barış içinde geldik, hediye ver, eve dönelim); earth actions on the moon are a noop with a reason.
- plus everything from before: who is good at X, make X minister (fuzzy names), meetings, assign / rest, demolish, trade N for M, name the settlement, tell X …, multi-intent.

Letters come from `mock/letters.js` templates that read the real state and offer 2–3 `says` options the parser can execute. Codegen returns a stock asset per keyword family (or code raised from the massing sketch) after `AGORA_MOCK_CODEGEN_MS` of status events (≈ 8 s by default: drafting at 0, writing at 25 %, checking at 80 %), and caches it like a real one.

**Live**: same routes, same normalisers, the model in the middle. Every live failure (401, 429, network, refusal, truncated JSON, code that fails validation 3 times, the codegen budget) logs a warning and falls back to the mock answer with `meta.liveError`.

## Model routing and why
| Route | Model | Effort | Why |
|---|---|---|---|
| command | `AGORA_MODEL_COMMAND` (= logic) | low | speech → actions should be < 4 s; measured 3.4–7.5 s on Fable (every demo phrase mapped right, incl. Turkish and multi-intent). Swap the model if speed beats nuance. |
| talk | `AGORA_MODEL_COMMAND` (= logic) | low | one or two plain sentences for a bubble; 15 s cap, one shot, the sim's mock behind it. Un-measured live (the key had no credit on 2026-10-04); the mock answered every intent through the real server. |
| sketch | `AGORA_MODEL_SKETCH` (= logic) | low | 3–10 primitives in seconds; 12 s cap, one shot. Measured live: 7.1 s on Fable at effort low with the long first prompt (the prompt is now ~half the size); set a smaller model here if the pencil must land under 4 s. |
| society | `claude-fable-5-1` | medium | 0–2 letters that must reflect state and stay in character; off the critical path. |
| letter | `claude-fable-5-1` | low | one letter in seconds (measured live 4–8 s). |
| minds/think · converse · reflect · persona talk | `AGORA_MODEL_PERSONA` = `claude-haiku-4-5` | (none: Haiku 4.5 has no effort ladder; thinking off) | twelve minds every 30–40 s must be cheap and quick: ≈ $0.002 a call with the persona prefix cached (4096-token minimum on Haiku 4.5, so the shared rules block is long). |
| minds/cast · direct | `AGORA_MODEL_DIRECTOR` = `claude-fable-5-1` | medium | twelve distinct personas once; the story's hand every 10 min (configurable, hourly for real sessions): the whole state, coherence over speed. |
| codegen | `claude-opus-5-5` | high | three.js in the painted grammar against the Build API; **fast mode first** (2× price, research preview, Claude API only), standard on 429/400/error. Streamed so the UI shows progress. |

Facts baked into `llm.js` / `routes.js` (from the bundled Claude API docs):
- **No `thinking` param** on either model. Depth is `output_config.effort`; Opus 5.5 defaults to `medium`, so it is set explicitly.
- **No forced `tool_choice`**, no temperature, no assistant prefill. JSON comes from structured outputs: `output_config.format = { type:'json_schema', schema }` with `additionalProperties:false` and every key in `required`.
- **Union-typed parameters are capped at 16 per schema** (live 400: "Schemas contains too many parameters with union types … limit: 16"). The flat action object therefore uses **empty values instead of null** (`""`, `0`, `[]`); only `at.x`/`at.z` and `say` are nullable (3 unions; society has 4). A test counts them.
- **Fast mode**: `speed:'fast'` + beta `fast-mode-2026-02-01` on `claude-opus-5-5` (also Opus 5 / 4.8; the server only sends it for those). Measured live: the fast lane returned 429 once and the standard lane answered in 8.8 s (948 output tokens). The fallback keeps the same conversation, so a repair after a fast→standard switch still works.
- **Server-side fallbacks**: `betas:['server-side-fallback-2026-07-01']` + `fallbacks:'default'` on every request; `usage.iterations` is checked to log when a fallback served the answer.
- **stop_reason** is checked before reading content: `refusal` and `max_tokens` become `MindError`s. Errors are classified most-specific-first.
- **Prompt caching**: the system is one text block with `cache_control: {type:'ephemeral'}`; the snapshot/transcript is the user turn after the breakpoint (live: letters show `cacheRead=2438` from the second call on).
- `max_tokens` is a hard cap on thinking + answer: logic routes 16000 (sketch 4000), codegen streams at 32000.
- **Data retention**: `claude-fable-5-1` requires 30-day retention; a zero-data-retention org gets `400 invalid_request_error` on every logic call.

## Codegen validation (audit rounds 1 + 3)
1. **Scan** (`scanForbidden`) on a tokenised view (`stripLiterals`: strings, comments and regex literals blanked, template `${}` expressions kept). Bans bare `window document self top parent frames location origin this fetch process navigator`, and anywhere `globalThis constructor __proto__ prototype getPrototypeOf setPrototypeOf defineProperty Reflect Proxy Symbol XMLHttpRequest WebSocket EventSource Image Audio Worker postMessage queueMicrotask structuredClone import export eval Function Promise async await yield fromAsync localStorage sessionStorage indexedDB caches cookie setTimeout setInterval setImmediate requestAnimationFrame require with(`, `while(true|1|!0|n)`, `for(;;)`, `do`, any `\u` escape outside a string, private fields, more than 24 loops, and (round 3) **string decoders** `fromCharCode fromCodePoint atob btoa codePointAt charCodeAt TextDecoder TextEncoder decodeURI(Component) unescape`.
2. **Raw string literals** (`scanLiterals`, round 3): the words `constructor __proto__ prototype Function globalThis window fetch eval process require import document fromCharCode atob` are rejected **inside any string literal** too (`api["constructor"]`, `"__pro"+"to__"` style smuggling). Comments are allowed to say "window sill".
3. **Strict prologue**: `harden(code)` prepends `'use strict';` and every asset is stored and served that way (the browser wrapper in `web/js/buildings/api.js` `compileAsset` adds it as well).
4. **Syntax**: parse-only `new Function` with the same prologue.
5. **Dry run** (`dryRun`): executes `build(api)` inside `vm.createContext(Object.create(null), { codeGeneration: { strings:false, wasm:false } })` with a 1.5 s timeout. The Proxy stub `api` is created inside the context; its `constructor` / `__proto__` / `prototype` getters **throw** (round 3), so a name assembled at runtime (`api["constr"+"uctor"]`) dies on the dry run even though the scan cannot see it.
6. **Process guards** (`installProcessGuards`): `unhandledRejection` and `uncaughtException` are logged, never fatal.
Code > 40 KB is rejected.

## Known gaps
- Live sketch latency on Fable at effort low was 7 s with the first prompt; the prompt is now shorter but un-measured with a key in hand. `AGORA_MODEL_SKETCH` exists for a faster model.
- Mock `send_gift` picks the gift bundle by keyword (bread → food 3 …); amounts above 50 are clamped.
- The stock boat / duck use `api.bob`, which `library.animate` must be ticking for them to float.
- Codegen validation cannot prove the code *renders*; `library.register` catches build-time throws in the browser. `DELETE` is not exposed; delete the JSON in `server/data/assets/` to forget a bad asset.
- The scan is a blacklist; the real guarantees are the strict prologue, the vm dry run (throwing stub) and the process guards.
- No Deepgram relay yet.
